# AI4Devs 2026-10 · Mauricio Palazuelos

Repositorio de trabajo del máster **AI4Devs: Augmented Software Engineering** de [LIDR](https://lidr.co), edición 2026-10.

Aquí reúno los ejercicios, prácticas y el proyecto final del programa, enfocado en aplicar inteligencia artificial en todas las etapas del desarrollo de software: análisis, diseño, desarrollo, pruebas, despliegue y monitoreo.
